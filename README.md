# وفير (Wafeer) - تطبيق إدارة المعاملات المالية

تطبيق Flutter احترافي لحفظ وإدارة المعاملات المالية اليومية (دخل ومصروفات) مع تتبع الميزانية الشهرية.

## ✨ الميزات
- ✅ تسجيل الدخل والمصروفات وحساب الرصيد تلقائياً
- ✅ تصنيف المعاملات (طعام، تسوق، مواصلات، ترفيه، فواتير، راتب، أخرى)
- ✅ تحديد ميزانية شهرية مع شريط تقدم ذكي وتنبيهات التجاوز
- ✅ رسم بياني لتوزيع المصروفات حسب الأقسام
- ✅ بحث وتصفية المعاملات
- ✅ تصميم عصري داكن (Dark Mode) وأنيق

## 🛠️ التقنيات المستخدمة
- **Flutter 3.x** - إطار العمل الأساسي
- **Provider** - إدارة الحالة
- **intl** - تنسيق التواريخ والأرقام

## 🔨 كيفية البناء محلياً
```bash
flutter pub get
flutter build apk --release
```

## 📱 ملف الـ APK
يتم بناء ملف APK تلقائياً عبر GitHub Actions عند كل رفع للكود.
يمكن تحميله من تبويب **Actions > أحدث Run > Artifacts**.
